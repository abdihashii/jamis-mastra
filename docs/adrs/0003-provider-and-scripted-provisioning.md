# Provider: Hetzner CPX21 in EU, provisioning via cloud-init + thin scripts

The production VPS is a Hetzner Cloud CX23 (2 vCPU / 4GB RAM / 40GB SSD, $6.49/mo, cost-optimized shared vCPU line) in Falkenstein (fsn1), Ubuntu 24.04. Chosen over DigitalOcean 4GB/$24/mo (US): same RAM at a quarter of the price, and over the CPX performance line (newer CPUs this workload can't feel). Escape hatch: CX33 (8GB, $8.99/mo)., and the latency costs are negligible for this workload (Cloudflare edge terminates public TLS near clients; LLM generations dominate response times; deploys are non-interactive SSH one-liners). Accepted costs: ~100-130ms RTT for interactive SSH/Studio, +~100ms per Fireworks LLM call, EU data residency.

Provisioning is a cloud-init user-data file plus two thin shell scripts in `infra/` (`provision.sh` wraps `hcloud`/`doctl` create with the user-data; `deploy.sh` wraps the SSH git-pull-and-compose-up deploy). Chosen over Terraform/Ansible: one box, one operator, and the scripts make the box disposable, switching providers or resizing means re-running provision, not migrating. Docker is installed from its official apt repository, not the get.docker.com convenience script (self-declared not for production).
